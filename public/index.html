READ-ONLY SEARCH

Exact matches only. Up to 256 characters; no wildcard search.

Profiles are grouped by their source profile and MFA device.

Search scope

Choose up to 250 profiles sharing a source identity and MFA device.

Searches only each selected profile’s configured region: role region, then source region, or us-east-1 by default. Other regions are outside this search.

Enter a fresh MFA code for each read-only lookup. You do not need to enter another code while that search runs. Large searches can take up to 10 minutes; any unfinished profiles are marked Not checked. Console switching continues through your existing browser session and needs no MFA code in this app.

No lookup runs until you select Search resources.
